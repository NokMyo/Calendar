# Smart Wall Calendar

Raspberry Pi 기반 벽걸이 스마트 캘린더 프로그램입니다.

기술 스택:

- TypeScript
- React
- Electron
- SQLite (`better-sqlite3`)
- Vite

## 개발 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm start
```

## 주요 기능 초안

- 전체화면 캘린더 UI
- 월간 달력 표시
- 날짜 선택
- 선택한 날짜의 일정 표시
- SQLite 기반 일정 저장
- SQLite 기반 설정 저장
- 날씨 카드 UI
- 설정 화면 UI

현재 커밋은 v0.1 골격입니다.
